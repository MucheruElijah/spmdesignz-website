How to get your Signature with Circular Icons into Spacemail

We designed this signature in the exact layout as your client's (Circular logo, vertical brand accent line, bold title, website link, and circular social icons):

  1. Click Copy Signature below.
  2. Open Spacemail > Settings > Signatures.
  3. Paste (Ctrl + V) into the signature box.
  4. If Spacemail's editor doesn't display the images on paste: use the Image icon (🖼️) on Spacemail's toolbar to insert the icons directly, then link each one using the Link icon (🔗)!
